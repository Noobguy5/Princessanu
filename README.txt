PRINCESS DAY WEBSITE — FOR PRINCESS, FROM PIYUSH
================================================

CONTENTS
- index.html: Complete self-contained website (HTML, CSS and vanilla JavaScript).

OPEN LOCALLY
1. Extract the ZIP file.
2. Open the folder.
3. Double-click index.html, or open it in a modern browser.
4. For best results, use a recent version of Chrome, Safari, Firefox or Edge.

PUBLISH WITH GITHUB PAGES
1. Create a GitHub repository.
2. Upload index.html to the repository root.
3. Open Settings > Pages.
4. Select Deploy from a branch, choose the main branch and /(root), then Save.
5. Wait for GitHub Pages to publish the site.

EDITING THE CONTENT
- Open index.html in a text editor.
- Search for the visible text you want to change.
- Page 4's typewriter letter is stored in the JavaScript variable named letterText.
- Page 5's eight appreciation cards are stored in cardData.
- Page 6's gift descriptions are in the giftlist section.
- Page 7's promises are in the promise-list section.
- Page 8's final letter and signature are in the p8 section.

NOTES
- The project uses no framework, npm, build step, backend or database.
- Google Fonts are loaded from the internet; system fallback fonts are provided.
- Sound is off by default. The sound button enables small generated interaction tones after a user click; there is no autoplay music.
- The site is responsive and includes reduced-motion support.
- All illustrations are inline SVG, emoji and CSS; there are no external image files to manage.
- Progress is not persisted between reloads. Refreshing starts from Page 1.
